# Passive Scan v8.5.2

제공된 Community Security Lab 3.4.0의 고정 권한 표본을 로컬에서 재현하는 실행기를 추가했습니다. 네 계정의 로그인·신원을 별도 CookieJar로 확인하고 비공개 데이터 본문과 수정 경로를 대조합니다. JSONL·HTML·Excel·증거를 저장합니다.

CLI 진단은 실행 이벤트 자체가 없는 `CLI_EVENT_TIMEOUT`과 실행 시작 후 첫 모델 응답이 없는 `FIRST_RESPONSE_TIMEOUT`을 구분합니다. 실패 기록에는 안전한 수치만 남기며 원문 stderr·인증정보를 복사하지 않습니다.

검증: 로컬 165개 테스트 중 163개 통과·선택 Chromium 2개는 CI에서 별도 실행. 새 로컬 요청 61건으로 권한 50표본을 검사했고, 5자원에서 비인가 반환 13표본과 내부 오류 노출을 재현했습니다. 수정 경로 25/25 정책 대조 및 오류 대조가 통과했습니다. 13표본은 독립 취약점 13개를 뜻하지 않습니다.

이 버전도 실제 모델 검토가 남은 사전 배포입니다. ChatGPT 로그인·설정은 통과했지만 probe가 실행 이벤트 0건의 CLI_EVENT_TIMEOUT으로 끝났습니다. 자동 모델 완료는 0/22이며 모델 성능은 측정하지 않았습니다. ChatGPT 로그인 Codex CLI면 충분하며 Pro 구독 확인은 완료 조건이 아닙니다.
