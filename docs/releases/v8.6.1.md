# Passive Scan v8.6.1

저장 증거 분석용 Codex CLI가 첫 이벤트 전에 멈추던 프로젝트 문서 탐색 경로를 분리하고, CLI의 비치명적 경고를 도구 실행으로 잘못 판단하던 문제를 수정했습니다. 모델이 거부하던 `uniqueItems`는 전송 스키마에서만 제외하고 로컬 중복 검증을 유지했습니다. 기존 ChatGPT 로그인으로 실제 모델 probe의 응답과 완료 검증을 통과했습니다. 긴 분석의 정상 응답을 너무 일찍 중단하지 않도록 배치 첫 응답 대기를 기본 180초로 조정했고 전체 실행 제한은 300초로 유지했습니다.

분석 프로세스에서 사용자 훅·알림 명령·셸 스냅숏·번들 스킬 설치를 끕니다. 기존 인증·사용자 설정·관리 정책과 읽기 전용 샌드박스는 유지합니다. 실제 도구 호출, 실패 이벤트, 잘못된 결과·인용은 계속 거부합니다.

전송 스키마에는 실제 패킷·관찰 ID 목록을 넣어 존재하지 않는 증거 ID 생성을 제한합니다. 서비스 enum 크기 제한과 로컬 결과·인용 검증은 유지합니다.

실제 저장 증거 36/36개 패킷, 77개 기록·82개 조각 검토를 완료했습니다. 기존 라벨 50건은 TP 13·TN 35·FP 2·FN 0입니다. 정상 대조군이 의심 의견에 연결된 오탐 2건과 개별 인용이 없는 2건은 그대로 기록했습니다. 새 대상 요청은 없으며 이 표본의 성능을 일반화하지 않습니다.
