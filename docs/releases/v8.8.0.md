# Passive Scan v8.8.0 — PortSwigger 주제 기반 후보 추천

PortSwigger Academy의 취약점 관련 30개 주제를 33개 추천 유형에 연결했습니다. SSRF·XXE·경로 탐색·명령어/템플릿/NoSQL 주입·CORS·클릭재킹·Host·캐시·인증 등 저장 단서를 확장합니다.

- 단서 후보와 API·GraphQL·OAuth/JWT·LLM·업로드·경쟁 상태 등의 기능 점검 대상을 구분합니다. 일반 기능 사용 자체를 결함으로 표시하지 않습니다.
- 모든 유형의 구현 범위·출처·부족한 자료를 제공합니다. 원시 전송을 생략한 요청 스머글링은 미평가로 표시합니다.
- 기본 AI 예산은 단서 최대 24개·8개씩·동시 2개로 유지합니다. `--ai-include-surfaces`는 기능 점검 대상을 같은 예산 안에 포함합니다.
- CORS의 `Access-Control-Allow-Credentials` true/false 과잉 마스킹을 수정했습니다. 실제 자격정보와 과거 마스킹 값은 계속 보호합니다.

취약점 확정·자동 공격·키 인증·대상 추가 요청은 수행하지 않습니다. Burp Scanner의 모든 개별 검사 구현을 뜻하지 않습니다. httpx 20워커 및 각 `-rl 10 -t 5`는 유지합니다.
