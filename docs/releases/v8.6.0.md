# Passive Scan v8.6.0

전체 소스 검토에서 발견한 수집 누락·이전 범위 증거 잔존·서명 URL 마스킹·요청 예산·GraphQL POST 승인·응답 완전성·AI 결과 발행 문제를 보완했습니다. JS 분석은 전체 추출을 자산별 SQLite에 저장하며, 기존 상세 Excel과 새 보고서를 공통 인벤토리로 연결했습니다.

OpenAPI 공유 참조·AI 본문 해시·비교 응답 파싱·배치 검증의 반복 작업을 줄였습니다. 계정 비교 중심 AI 패킷, 반복 수집 이벤트 이력, 큰 HTML 보고서 분할을 추가했습니다. httpx20워커·각 `-rl 10 -t 5`는 유지합니다.
