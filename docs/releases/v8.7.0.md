# Passive Scan v8.7.0 — 여러 취약점 유형의 후보 추천

저장 요청·응답을 규칙으로 선별해 IDOR·인가, XSS, SQLi, 민감정보, API KEY·TOKEN·비밀값 후보를 추천합니다. 새 `ai_review.py recommend`는 후보별 근거·다음 확인·검토 상태를 HTML/JSON으로 제공합니다.

- 기본 모델 호출 0회. `--ai`를 지정하면 우선 후보 최대 24개만 8개씩 묶어 동시 2개로 짧게 검토합니다.
- 의심 대상과 정상 대조군을 분리하고 근거 위치·결과 ID·모델 완료 영수증을 검증합니다.
- 미선택·실패·큰 맥락의 후보를 목록에 남깁니다. 기존 `batch-*`와 과거 보고서를 보존합니다.
- 취약점 확정·자동 재현·대상 추가 요청·비밀값 유효성 확인은 수행하지 않습니다.
