# Passive Scan v8.9.0 — 저장 증거 분석·AI 재사용·사람 판정

저장된 요청·응답에 관련 증거와 응답 차이를 연결하고, 동일 입력의 검증된 AI 결과를 재사용합니다. `--ai --discover`는 규칙 밖 저장 자료에서 제한된 후속 점검 가설을 찾습니다.

- 정상 비교 자료와 실제 의심 대상을 분리하고, 저장 값 흐름은 추정 관계로 표시합니다.
- 새 검토는 기본 24단위 안에서 규칙 후보와 탐색 묶음이 공유합니다. 재사용은 새 호출로 집계하지 않습니다.
- 사람의 채택·기각·보류를 전체 증거 해시에 연결하고 다음 추천의 순서·제외에 반영합니다.
- HTML에서 관련 기록·응답 차이·원문 위치·사람 판정을 확인할 수 있습니다.

분석 경로의 대상 추가 요청·DNS는 0건입니다. 선택한 증거의 모델 서버 통신은 발생합니다. 자동 재현·키 인증·최종 취약점 확정은 하지 않습니다. 기존 수집 설정 httpx 20워커 및 각 `-rl 10 -t 5`, PortSwigger 30주제/33유형과 과거 실행 기록을 유지합니다.
