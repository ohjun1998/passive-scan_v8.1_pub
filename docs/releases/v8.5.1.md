# Passive Scan v8.5.1

실제 검토를 시작하기 전에 Codex 설치·ChatGPT 로그인·설정·모델 연결을 따로 진단할 수 있습니다. `ai_review.py doctor --probe`는 저장 증거 없이 고정된 JSON 응답만 시험합니다.

- 첫 응답 제한을 지정하고 배치 시도 기록에 남깁니다.
- CLI 없음과 완료 결과 누락을 구분합니다.
- 집계 보고서와 평가에 Codex·수동/미검증·미완료 출처를 연결합니다.
- 날짜별 작업 대화와 남은 단계를 문서화했습니다.

검증: 로컬 158개 테스트 중 156개 통과, 선택 Chromium 2개는 GitHub CI에서 별도 실행합니다. 기존 실습 ZIP의 104개 파일 해시와 77기록→22패킷 준비를 확인했습니다. 평가 라벨 50개는 해당 기존 실습에 한정됩니다.

이 버전은 자동 모델 실행 검증이 남아 있는 사전 배포입니다. 실제 연결 시험은 FIRST_RESPONSE_TIMEOUT으로 끝났으며, 자동 완료 0/22·실제 모델 성능 평가·새 재현은 미완료입니다. 실제 모델 성공이나 Pro 구독 등급을 보증하지 않습니다.
