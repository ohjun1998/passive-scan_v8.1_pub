ChatGPT 계정에 로그인한 Codex CLI로 저장 요청·응답을 분석하는 방식이 현재 실행 경로입니다. Pro 등급 확인이나 별도 Pro 모드는 완료 조건이 아닙니다. 설정 검사를 통과한 것과 실제 모델 실행 완료는 구분합니다.

## CLI 실행 이벤트 구분

```bash
python ai_review.py doctor --probe --timeout 180 --first-response-timeout 120 --output reports/doctor-v852
```

`CLI_EVENT_TIMEOUT`은 제한 시간까지 인식 가능한 CLI 실행 이벤트가 하나도 도착하지 않은 상태입니다. `FIRST_RESPONSE_TIMEOUT`은 실행 이벤트가 도착했지만 첫 reasoning/agent_message가 없는 상태입니다. 두 코드만으로 인증·네트워크·사용량 등 근본 원인을 확정하지 않습니다. 기존 `--first-response-timeout` 설정을 두 경우에 적용하며 무제한 재시도를 추가하지 않습니다.

doctor와 배치 실패 시도에는 이벤트 수·stdout/stderr 바이트 수·첫 모델 응답 여부·경과 시간만 저장합니다. 원문 stderr나 인증정보는 진단 자료로 복사하지 않습니다. 실행 영수증·완료 이벤트·결과·인용 검증을 모두 통과해야 실제 Codex 완료로 집계합니다. 기존 [재개·보고서·평가 명령](V851.md)은 그대로 사용할 수 있습니다.

2026-10-15 후속 시험: CLI 0.162.1, ChatGPT 로그인·기능·MCP 설정 통과. 전체 제한 20초·첫 응답 제한 12초의 증거 없는 probe는 `CLI_EVENT_TIMEOUT / startup`으로 끝났습니다. 이벤트 0건, stdout 0바이트, stderr 119바이트, 모델 응답 없음, 경과 12.009초였습니다. 앞선 직접 실행·선택 기능 비활성화·런타임 환경 전달 시험도 완료 결과를 얻지 못했습니다. 사용자 설정을 제외한 추가 시험도 18.014초 동안 이벤트·stdout·stderr 모두 0으로 끝났습니다. 원인은 미확정이며 실제 모델 자동 완료는 여전히 **0/22**입니다.

## 제공된 Community Security Lab 3.4.0 재현

새 `examples/community_reproduce.py`는 제공된 교육용 실습 서버의 고정 표본을 재현합니다. 해당 서버를 실습 패키지 안내에 따라 로컬에서 실행한 뒤 사용합니다.

```bash
python -m pip install -r requirements-v81.txt -r requirements-report.txt
read -rsp 'Local lab password: ' PASSIVE_LAB_PASSWORD
export PASSIVE_LAB_PASSWORD
python examples/community_reproduce.py --target http://127.0.0.1:18090 --output reports/community-reproduction
unset PASSIVE_LAB_PASSWORD
```

출력은 새 디렉터리를 요구합니다. HTTP 리터럴 loopback IP만 허용하고, 환경 프록시·리다이렉트를 사용하지 않습니다. 고정 경로·최대 64요청·60초 예산·요청별 5초·응답 64KiB 상한을 적용합니다. 네 계정은 별도 CookieJar로 로그인하고 같은 세션의 `/api/auth/me`에서 ID/역할을 확인합니다. 비밀번호·쿠키는 저장 전 마스킹합니다. 중간 실패 시에도 수집분과 실패 상태를 남깁니다.

`capture.jsonl`, `reproduction.json`, `base-report/index.html`, Excel·증거·해시 manifest를 생성합니다. 이 결과는 실습 정책에 대한 독립 로컬 재현이며 실제 AI 검토나 운영 서비스 최종 확정으로 집계하지 않습니다.

| 재현 항목 | 이번 실제 결과 |
|---|---|
| 새 로컬 HTTP 요청 | 61건 |
| 같은 CookieJar 신원 확인 | 4/4 |
| 권한 표본 | 50개: 5자원 × 취약/수정 경로 × 5역할 |
| 허용되지 않은 실제 데이터 반환 | 13표본: 주문 3·게시글 2·쪽지 2·비공개 파일 3·관리자 목록 3 |
| 수정 경로 정책 일치 | 25/25 |
| 오류 내부정보 노출 | SQL·Spring JDBC 예외 노출 재현, 수정 경로 대조 통과 |

13은 계정·경로 조합별 표본 수이며 독립 취약점 13개라는 뜻이 아닙니다. 상태 코드 200만으로 판단하지 않고 실습의 비공개 데이터 표식·소유자 필드를 검사합니다. 거부 응답에 비공개 데이터가 있어도 수정 대조 성공으로 처리하지 않습니다.

## 검증과 남은 작업

로컬 테스트 165개 중 163개 통과, 선택 Chromium 2개는 CI의 실제 브라우저 작업에서 검증합니다. 새 회귀 테스트 7개는 무이벤트 시간 초과·안전한 진단·실패 코드 보존·로컬 범위·리다이렉트·본문 증거·허용/거부 대조를 확인합니다. 기존 전달 ZIP의 파일 해시 167개와 22패킷 불변성을 다시 확인했습니다.

남은 순서: 실제 실행 환경에서 probe 완료 → 기존 22패킷 실행 → fragment/인용/완료 출처 확인 → 기존 50표본 라벨로 모델 평가 → 사람 검토 후 최종 AI 보고서 확정. 이번 로컬 재현의 표본 ID와 기존 77기록의 ID는 별개이며 섞어서 평가하지 않습니다. httpx **20워커, 각각 `-rl 10 -t 5`**는 유지합니다.
