[유스케이스](USE_CASES.md) · [전체 처리 흐름](FLOW_V85.md) · [남은 단계](REMAINING_STEPS.md)

## 실행 전 확인

```bash
python -m pip install -r requirements-v81.txt -r requirements-report.txt
python ai_review.py doctor --output reports/doctor-config
```

기본 doctor는 Codex 버전, 기존 ChatGPT 로그인, 기능과 MCP 설정 형식을 검사합니다. 모델 추론 요청을 보내지 않으며 ready여도 모델 실행 성공을 의미하지 않습니다. CLI가 없으면 CLI_NOT_FOUND와 cli 단계를 기록합니다. 원문 stderr·인증 토큰·저장 증거를 진단 JSON에 복사하지 않습니다. --output에는 새 디렉터리를 지정하세요.

Codex CLI를 설치하고 해당 컴퓨터에서 `codex login`을 완료한 다음, 증거 없이 연결을 시험합니다. CLI가 지원하는 실제 모델 ID를 선택적으로 --model에 지정할 수 있습니다. API 키로 자동 대체하지 않습니다.

```bash
python ai_review.py doctor --probe --timeout 180 --first-response-timeout 120 --output reports/doctor-probe
```

--probe만 고정된 `{"ready":true}` 응답을 모델 서비스에 요청합니다. read-only·ephemeral·도구/웹/MCP 제한과 완료 이벤트 검사 경로는 실제 배치와 같습니다. 완료 이벤트와 정확한 boolean 결과가 모두 있어야 model_execution_verified가 true가 됩니다. 설정 확인만으로 구독 등급이나 실제 모델 성공을 표시하지 않습니다.

## 저장 증거 검토 재개

```bash
python ai_review.py batch-run --batch reports/ai-batch --timeout 300 --first-response-timeout 120
python ai_review.py batch-run --batch reports/ai-batch --timeout 300 --first-response-timeout 120 --retry-failed --max-attempts 3
python ai_review.py coverage --batch reports/ai-batch
```

기본 첫 응답 제한은 기존과 같은 60초입니다. 1~3,600초로 지정할 수 있고 전체 실행 제한보다 길면 전체 제한을 적용합니다. 값은 각 시도 기록에 남습니다. 첫 reasoning/agent_message 도착을 기다리는 제한이며 전체 모델 실행의 제한과 별개입니다. 시간을 늘리는 설정은 인증·연결·사용량 문제의 해결을 보증하지 않습니다.

실패한 패킷은 --retry-failed를 지정해야 다시 시도합니다. 완료 패킷은 원본·결과·인용 해시를 검사한 뒤 재사용합니다. 묶음당 시도 상한 3회는 유지합니다. 잘못된 시간·모델 설정은 시도 횟수를 소비하기 전에 거부합니다. 배치가 미완료이면 기존처럼 종료 코드 3을 반환하며, 이 동작은 이번 패치 전부터 구현돼 있었습니다.

## 보고서·평가

```bash
python ai_review.py batch-report --batch reports/ai-batch --output reports/ai-report
python ai_review.py evaluate --review reports/ai-report --labels imports/labels.json --output reports/evaluation
python ai_review.py pdf --review reports/ai-report --output reports/ai-report.pdf --font /path/to/KoreanFont.ttf
```

집계 execution.json의 packet_execution_counts는 codex_verified / manual_or_unverified / incomplete를 구분합니다. 모든 패킷의 로컬 실행 영수증에 완료·Codex 실행·이벤트 확인·인용 검사가 기록돼 있어야 집계 model_execution_verified가 true입니다. 수동으로 가져온 의견은 인용이 맞아도 Codex 실행으로 집계하지 않습니다. 평가 JSON의 execution_provenance에도 같은 출처가 연결됩니다. 로컬 영수증은 암호학적 모델 증명이 아니며, 인용 일치는 의미·취약점·재현의 보증이 아닙니다.

## Troubleshooting

| 코드 | 확인할 단계 |
|---|---|
| CLI_NOT_FOUND | 실행 컴퓨터의 PATH에 codex가 있는지 확인 |
| CHATGPT_AUTH_REQUIRED / AUTH_REQUIRED | 해당 컴퓨터에서 codex login 확인 |
| UNSUPPORTED_CLI | CLI 버전·기능 목록과 지원 옵션 확인 |
| NETWORK_ERROR / RATE_LIMIT | 모델 서비스 연결 또는 사용량 문제 확인 |
| FIRST_RESPONSE_TIMEOUT | 제한 안에 첫 응답 미도착. 원인은 이 코드만으로 확정하지 않음 |
| EXECUTION_TIMEOUT | 전체 실행 시간 초과 |
| RESULT_MISSING | 완료 이벤트 이후 결과 JSON이 없는 상태 |
| INVALID_PROBE_RESULT | 연결 시험의 JSON 결과가 계약과 다른 상태 |
| INVALID_CLI_CONFIGURATION_OR_RESULT | 설정 또는 연결 시험 결과 형식 확인 |

2026-10-15 실행 기록: CLI 0.162.1, ChatGPT 로그인·기능·MCP 설정 검사 통과. 증거 없는 probe는 45초 첫 응답 제한에서 FIRST_RESPONSE_TIMEOUT. 전체 실행 제한은 60초였으며 완료 이벤트·결과는 없었습니다. 실제 모델이 어떤 이유로 응답하지 않았는지는 확인되지 않았습니다. 이 시험에서 실제 증거를 모델에 보내거나 새 대상 요청을 하지 않았습니다.

기존 실습 결과 ZIP의 해시 104개를 확인하고 77기록을 22패킷으로 다시 준비했습니다. 신원 4개·정책 50개를 연결했으며, 기존 독립 실습 검증 기록에 근거한 평가 라벨 50개(의심 기준 13개)를 준비했습니다. 현재 자동 완료 패킷은 0/22입니다. 이 라벨은 해당 로컬 실습 표본의 기존 관찰에 한정되며, 실제 모델 성능 수치나 새로운 재현 성공으로 해석하지 않습니다.

공식 실행 규격: [Codex non-interactive mode](https://developers.openai.com/codex/noninteractive), [CLI reference](https://developers.openai.com/codex/cli/reference). 저장 로그인 재사용, --json·--output-schema·-o 규격을 참고했습니다. 현재 환경의 연결 성공 여부는 위 실제 진단 기록을 기준으로 합니다.
