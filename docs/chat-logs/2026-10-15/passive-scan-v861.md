이전 PR #5의 main 병합·배포 승인을 확인하고, AI 실행 정지 해결과 저장 요청·응답의 실제 모델 검증을 진행했다.

## 완료한 작업

- PR #5를 `911bd7355c916a884c0bb77e80944460b30fe66a`로 병합했다. main CI와 Source release가 성공했고 v8.6.0 태그·소스 ZIP·SHA256SUMS가 같은 커밋을 가리킴을 확인했다.
- 기존 ChatGPT 로그인과 설정을 유지하며 CLI 0.158.0·0.159.2·0.162.1, 프록시 전달, 세션 방식, 임시 위치, 상태 DB, 최대 120초 대기를 비교했다.
- 분석용 자식 CLI에서 프로젝트 문서 탐색을 생략하자 즉시 세션 시작 이벤트가 발생했다. 호출자의 저장소 지침과 관리 정책·읽기 전용 샌드박스는 유지했다. 내부 샌드박스 파일 조회의 정확한 정지 원인을 단정하지 않았다.
- `item.type=error`인 비치명적 경고를 도구 실행으로 오인하는 검사를 수정했다. 실제 도구 호출·최상위 실패는 계속 거부하며, 경고만으로 모델 응답이나 완료를 인정하지 않는다.
- 실제 doctor probe가 모델 응답·완료 검증을 통과했다. 기존 인증·사용자 설정은 수정하지 않았다.
- 첫 실제 리뷰에서 HTTP 400 `invalid_json_schema`와 미지원 `uniqueItems`를 확인했다. 전송 복사본만 조정하고 저장된 스키마·중복 ID·인용 검사를 유지했다.
- 훅·알림·셸 스냅숏·번들 스킬 설치를 분석 자식 프로세스에서 비활성화했다.
- 로컬 268개 테스트 중 264개 통과, 실제 브라우저·외부 도구 4개는 CI에서 검증하도록 남겼다.
