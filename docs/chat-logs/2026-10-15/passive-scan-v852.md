## 남은 단계 실행 요청

사용자:

> 남은 단계 진행해줘

수행 내용:

1. 기존 v8.5.1 전달 ZIP과 제공된 Community Security Lab 3.4.0을 복원했다. 복원 ZIP 해시 167개 및 기존 22패킷 불변성을 재검사했다. 기존 자료 77기록·신원 4개·정책 50개·평가 라벨 50개는 그대로 보존했다.
2. Codex CLI 0.162.1의 기존 ChatGPT 로그인·기능·MCP 설정 통과를 확인했다. 직접 실행, 선택 기능 비활성화, 필요한 런타임 환경 전달 시험도 완료 결과를 얻지 못했다. API 키로 대체하거나 무제한 재시도하지 않았다.
3. 새 진단에서 무이벤트 CLI_EVENT_TIMEOUT과 실행 후 첫 응답 시간 초과를 구분했다. 최신 증거 없는 probe: 전체 20초·첫 응답 12초, 실제 경과 12.009초, 이벤트 0·stdout 0·stderr 119바이트·모델 응답 없음. 원인은 확정하지 않았다. 사용자 설정 제외 시험에서는 MCP 비활성화 오버라이드가 빈 설정 항목을 만드는 문제를 수정한 뒤 다시 시험했지만, 18.014초 동안 이벤트·stdout·stderr 모두 0이었다. 해당 시험 변경은 효과가 없어 제품 코드에 넣지 않았다. 실제 저장 증거 검토를 성공으로 표시하지 않았다.
4. Java 17과 제공 WAR를 이용해 loopback에서 실습 서버를 실행했다. 같은 실행 세션에서 서버와 재현 클라이언트를 실행해야 이 환경의 localhost에 접속되는 점을 확인했고, 모든 작업 후 서버를 종료했다.
5. 새 고정 표본 재현기를 추가했다. 로컬 IP만 허용하고 환경 프록시·리다이렉트를 사용하지 않는다. 네 계정의 CookieJar와 같은 세션 신원을 확인하고 고정 경로·64요청·60초 예산을 적용했다.
6. 최종 코드로 새 로컬 요청 61건을 보냈다. 권한 50표본에서 5자원 유형의 비인가 데이터 반환 13표본과 SQL·내부 예외 노출을 재현했다. 수정 경로 25/25 정책 및 오류 대조가 통과했다. 이 수치를 모델 정확도나 운영 서비스 확정으로 해석하지 않는다.
7. 신규 회귀 테스트 7개를 포함한 165개 테스트 중 163개 통과·선택 Chromium 2개 생략을 확인했다. CI에서 Python 세 버전과 실제 Chromium을 검증한다.
8. 재현 JSON·마스킹된 JSONL·HTML·Excel 및 전달용 PDF/검증 자료를 정리한다. 공개 GitHub에는 코드와 비민감 요약만 반영한다.
9. v8.5.2 버전·실행 안내·남은 단계·유스케이스·배포 안내를 갱신했다. 실제 모델 22패킷 검토·기존 라벨 평가·최종 AI 보고서는 CLI 정상화 후 남는다.
