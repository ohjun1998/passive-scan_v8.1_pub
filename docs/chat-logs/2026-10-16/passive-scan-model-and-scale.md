## 설명과 변경

- 이전 36묶음 전체 증거 검토와 v8.9 후보 추천 경로를 구분했다. 기록·후보·CLI 검토 묶음·내부 모델 호출 수가 서로 다름을 설명했다.
- 현재 코드의 모델 미지정과 추론 강도 미지정을 확인하고 공식 문서를 바탕으로 Sol medium 기본, 어려운 후보의 별도 심층 검토를 제안했다.
- 사용자가 지정한 기본값 gpt-6.1-sol / medium을 프로젝트 CLI와 공통 transport에 명시했다. 전역 CLI 설정은 변경하지 않았다. 기존 모델 옵션은 유지했다.
- 요청 모델·강도를 실행 기록·진단·추천 설정과 캐시 지문에 반영했다. 과거 검증 수치를 새 모델의 결과로 바꾸지 않았다.
- 기존 새 검토 예산 24단위·규칙 후보 최대 8개/묶음·동시 2개와 수집 설정은 유지했다. 전체 batch 경로는 별도의 순차 처리임을 문서화했다.
- 작은 합성 JSON 기록 5,000건의 오프라인 추천을 1.304초에 완료했다. 100후보에서 선택·패킹만 계산한 결과는 24후보/3묶음이며 실제 모델 호출은 없었다. 대량 자료의 기존 크기·후보·보고서 한계를 명시했다.
- 검증 결과는 [MODEL_SCALE_VERIFICATION.json](../../MODEL_SCALE_VERIFICATION.json), 변경 유스케이스는 [USE_CASES.md](../../USE_CASES.md)에 기록한다.
