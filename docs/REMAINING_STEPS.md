## 다음 실행 순서

1. 실제 실행 컴퓨터에서 [doctor --probe](V86.md)를 정상 완료한다. 현재 실행 이벤트 자체가 없어 시간만 늘렸다고 해결로 표시하지 않는다.
2. 새 비교 정책으로 준비한 batch를 batch-run으로 실행한다. 기존22패킷과 새36패킷을 섞거나 덮어쓰지 않는다. 실패 패킷만 --retry-failed로 명시적으로 재개한다.
3. coverage와 batch-report로 전체 패킷·모든 fragment·인용·비교 묶음 범위·실행 출처를 확인한다.
4. 기존 labels.json으로 evaluate를 실행한다. 새 재현 ID와 기존 라벨 ID를 섞지 않는다.
5. 모델 의견과 독립 재현을 검토하고 최종 AI 보고서/PDF를 확정한다.

실습 재현 결과를 모델 실행 성공·모델 정확도·운영 서비스 취약점 확정으로 표시하지 않습니다. [v8.6 안내](V86.md) · [검증 요약](V86_VERIFICATION.json) · [이전 실습 재현](V852.md). httpx **20워커 및 각 `-rl 10 -t 5`**는 유지합니다.
