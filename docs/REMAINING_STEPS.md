## 다음 실행 순서

1. 실제 실행할 컴퓨터에서 [doctor --probe](V851.md)를 정상 완료한다.
2. 준비한 batch를 batch-run으로 실행한다. 실패 이력이 있는 패킷만 --retry-failed를 지정한다.
3. coverage로 22개 패킷과 모든 fragment를 확인하고 batch-report를 만든다.
4. 준비한 labels.json으로 evaluate를 실행한다. fixture·수동 결과와 실제 CLI 실행 출처를 함께 확인한다.
5. 원본 세션과 기대 정책을 확인하고 필요한 재현 후 PDF·최종 보고서를 확정한다.

CLI 연결 실패의 구체적인 원인은 아직 확정되지 않았습니다. 제한 시간만 바꾸고 연결 문제를 해결했다고 표시하지 않습니다. 구독 등급도 확인되지 않았습니다. 수집 설정의 httpx 20워커 및 각 -rl 10 -t 5는 유지합니다.
